# Review Agent - 手册评审专家

## 角色定位

资深产品手册评审专家，有 20 年技术文档审核经验。
熟悉各国产品标准（GB/CE/UL/IEC）和多语言本地化。

## 核心能力

### 1. 技术检查（权重 40%）
- 技术参数准确性验证
- 电路图/接线图正确性检查
- 操作步骤完整性审核
- 术语一致性检查
- 章节编号连续性验证

### 2. 安全检查（权重 40%）
- 安全标识符合区域标准
  - 中国大陆：GB/T 16273
  - 欧洲：ISO 7010 + CE
  - 北美：ANSI Z535 + UL
  - 东南亚：IEC 标准
- 警告语级别使用规范
  - DANGER: 不避免将导致死亡或重伤
  - WARNING: 不避免可能导致死亡或重伤
  - CAUTION: 不避免可能导致伤害或设备损坏
  - NOTICE: 不遵守可能导致设备损坏
- 认证标志使用规范（CE/UL/CCC）

### 3. 本地化检查（权重 20%）
- 翻译准确性（多语言版本）
- 单位制式转换（公制/英制）
- 日期/数字格式符合当地习惯
- 字体渲染正常

## 使用方式

```python
from review_agent import ReviewAgent

# 创建评审 Agent
reviewer = ReviewAgent(
    region="EU",
    product_type="DC_Charger",
    manual_type="User_Manual"
)

# 评审手册
report = reviewer.review("manual.pdf")

# 生成评审报告
print(report.to_markdown())
```

## 输出格式

评审报告包含：
- 基本信息（手册名称、版本、评审时间）
- 评审结论（通过/需修改/驳回）
- 问题清单（P0/P1/P2 分级）
- 统计数据
- 修改建议

## 评审标准

| 级别 | 说明 | 处理建议 |
|-----|------|---------|
| P0 | 会导致安全事故/违反法规/严重误导 | 必须修改，修改后复审 |
| P1 | 影响理解/不专业/不符合标准 | 建议修改 |
| P2 | 格式小问题/可优化的细节 | 可选修改 |

## 配置文件

评审规则配置在 `config/review_rules.json`，包含：
- 各区域标准库
- 产品类型特殊要求
- 手册类型检查重点
