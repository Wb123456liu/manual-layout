## 🎨 设计规范

### 颜色方案

| 用途 | 颜色值 | 说明 |
|-----|--------|------|
| 主色调 | `#667eea` | 紫蓝色 |
| 渐变到 | `#764ba2` | 紫色 |
| 背景 | `#ffffff` | 白色卡片 |
| 文字 | `#333333` | 深灰 |
| 必填标记 | `#e74c3c` | 红色 |
| 成功提示 | `#d4edda` | 浅绿背景 |
| 边框 | `#e0e0e0` | 浅灰 |

### 字体

- **标题：** 28px，加粗
- **模块标题：** 18px，加粗
- **标签：** 14px，中等
- **输入框：** 14px，常规
- **提示文字：** 12px，浅灰

### 间距

- **模块间距：** 30px
- **表单项间距：** 20px
- **输入框内边距：** 12px 16px
- **圆角：** 8px

## 🚀 如何使用

### 步骤 1：打开表单

**方式 A：本地直接打开**
```bash
# 在文件管理器中找到
/root/.openclaw/workspace/manual-request-form.html

# 双击打开（用浏览器）
```

**方式 B：HTTP 访问**
```
http://localhost:8080/manual-request-form.html
```

**方式 C：服务器访问**
```
http://服务器公网IP:8080/manual-request-form.html
```

---

### 步骤 2：填写表单

1. **产品信息** - 填写产品名称、型号
2. **分类配置** - 选择区域、产品类型、手册类型
3. **输出要求** - 勾选需要的格式
4. **原始文档** - 提供飞书链接
5. **特殊要求** - 勾选必需内容，填写其他要求
6. **联系人** - 填写姓名和邮箱

---

### 步骤 3：提交

点击「🚀 提交排版需求」按钮

**提交后：**
- ✅ 自动下载 JSON 文件
- ✅ 显示 Request ID
- ✅ 显示预计完成时间
- ✅ 提示下一步操作
